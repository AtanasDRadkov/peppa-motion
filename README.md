Peppa Motion Mirror

A simple, interactive, motion-controlled game for children. Peppa mirrors the player’s body movements in real time using an iPhone camera.

Version 1

* Arm raising and waving
* Jumping and squatting
* Sideways movement
* Head tilting
* Kicking
* Live camera preview
* Simple light blue background

How to play

1. Open the app in Chrome on an iPhone.
2. Allow camera access.
3. Rotate the phone to landscape orientation.
4. Mirror the screen to a TV.
5. Position the phone underneath the TV with the camera facing the player.

Technology

* HTML, CSS and JavaScript
* TensorFlow.js
* MoveNet Lightning
* GitHub Pages

Privacy

Camera footage and body tracking are processed locally on the device. No video is uploaded or recorded by the application.
